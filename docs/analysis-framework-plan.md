## 1. 科学目标与待作决策

在 shotgun 宏基因组数据中识别候选质粒，描述其结构、分型、功能与潜在宿主；
在参考特征、计量方法与研究设计可比的前提下，研究跨样本质粒组成及丰度变化。
最终决定哪些候选值得进行结构、宿主或功能验证，以及哪些组间结论获得足够支持。

当前不能给出样本层面的结论：尚无本次任务对应的真实数据、分组、对照或结果。
默认参数只能建立计算起点，不能代替科学设计。

## 3. 实验设计与参考假设

- 实验单位：独立生物学样本 / 供体；技术重复、lane、read 不能作为独立重复。
- 分组、对照基线、配对、重复采样与时间因素：待明确。未提供时不预设疾病、处理或生态来源。
- 批次、测序深度、提取方法与宿主 DNA 比例：需要记录；完全混杂时对应对照不可识别。
- 当前差异脚本：内部 Welch 检验与 DESeq2 `~ group`，没有接入配对 / 批次模型。
  若数据需要这些因素，必须调整实现或另行使用适合的模型。
- 参考身份：分别记录候选识别、功能注释、宿主分类和可选预测模型的数据库版本 / 校验和。
  宏基因组不预设单一 genome build；若做宿主去除，应记录所选宿主参考组装及版本。
- 比较单位：候选序列、质粒 cluster、基因 / 功能、宿主候选分别命名，不混为同一种 feature。
- count 的计量单位必须声明为 read 或 fragment，并记录多重比对、配对及去重规则；
  TPM/RPKM/coverage 与原始计数分开保存。没有 spike-in 或其他标定时不声称绝对微生物负荷。

## 4. 分析路线

### A. 输入、质控与组装（00—03）

| 平台 | 输入 | 当前路径 | 特别边界 |
|---|---|---|---|
| Illumina | read1/read2 | fastp → MEGAHIT / metaSPAdes → QUAST；bowtie2 比对 | FastQC 默认关；MultiQC 默认开 |
| ONT | POD5 / BAM / FASTQ | 按需 Dorado / BAM 转换 → NanoPlot + Filtlong → metaFlye；可选 medaka | Dorado 需另外安装；map-ont |
| PacBio HiFi | BAM / HiFi FASTQ | HiFiAdapterFilt → hifiasm-meta；map-hifi | 当前未接 MultiQC |
| Hybrid | 双端短读 + ONT 长读输入 | 短 / 长读 QC → OPERA-MS / hybridSPAdes | 当前按 ONT 处理长读；不承诺任意 HiFi hybrid |
| Assembly | FASTA | 用户组装 → QUAST / 检测 | 无 read QC、丰度、MAG 或宿主关联分支 |

宿主去除由样本表 / 全局 `host_reference` 触发，须记录去除前后的读数、污染和参考身份。
验收需要实际 QC 报告、组装异常检查和对照行为，不能仅由 N50 或流程成功替代。

### B. 发现与结构证据（04—05）

geNomad 必选，其他检测器可选；输出逐工具判定、共识、候选 FASTA 和结构表。
默认只启用 geNomad，不自动构成多工具验证。

加权共识为支持权重 / 参与工具总权重 ≥0.5；默认四工具全部启用时 geNomad 权重为 0.6，
单独支持已可通过。阈值是工程规则，尚未用本次数据校准为概率。保留冲突、缺失结果与阈值敏感性。

当前结构脚本将 header、DTR、ITR 均可能标为 circular。分析验收应分别记录末端重复与真正闭环支持，
不将 ITR 自动解释为环形结构。图与跨接 reads 是后续复核输入；binning 是可选分支，
并非所有注释和定量都使用分箱重建后的结果。

### C. 分型、功能与序列比较（06 / 08 / 09）

默认 PlasmidFinder / MOB-typer，Bakta / AMRFinderPlus / ISEScan / IntegronFinder，
以及 MMseqs2 跨样本聚类。记录同源性、覆盖范围、基因上下文及数据库身份。
耐药基因注释不直接等于耐药表型；复制子 / 转移系统注释不直接等于实际转移事件。

MMseqs2 当前阈值为 identity 0.95、target coverage 0.8（`--cov-mode 1`），不是双向覆盖，
也不是已证明的普适质粒物种边界。评估截短序列、马赛克结构与不同阈值下 cluster 稳定性。

### D. 潜在宿主与关联（07）

MetaPhlAn / Kraken2 输出群落分类信息；PlasmidHostFinder / HOTSPOT 属于候选模型预测。
需要 MAG 的序列组成方法，应先核查最终 MAG 通道、质量和 taxonomy。

分别报告：

- 共丰度：Spearman/Pearson、Jaccard、p/q；组成性与混杂仍需处理，默认 q 阈值 1.0 不筛显著性。
- 序列组成：TETRA 风格四核苷酸 z-score 向量 Pearson 相关；启发式相似性，不是宿主后验概率。
- 长读桥接：同一 read 有 primary + supplementary 证据，且质粒 / 非质粒 contig 受支持；
  检查 MAPQ、独立分子、嵌合、重复、整合及非质粒 contig 的宿主归属。
- CRISPR：当前未实现，开启会被明确拒绝，不能写入“已支持证据”。

各证据不作未经校准的简单分数相加。必要时以 Hi-C、培养或针对性实验验证支持物理归属。

### E. 可比定量与生态统计（10—12）

**建议目标链：候选合并 → 稳定 catalog / cluster ID → 所有样本回贴同一参考 →
可追溯计数和丰度矩阵 → 设计适配的统计。当前尚未完整实现这条链。**

当前：每样本 reads 回贴本样本候选；DIVERSITY / 内部差异使用 contig 表；
DESeq2 / FastSpar 使用 plasmid 表，且在 raw_count 空缺时取整 coverage。
因此不能把现有统计文件直接表述为统一质粒目录上的差异 / 多样性结论。

不同端点的证据契约：

| 端点 | 必需输入与假设 | 通过前要看到的证据 | 不支持的结论 |
|---|---|---|---|
| 候选质粒存在 | 通过 QC 的序列、有效数据库、方法输出 | 序列与逐工具结果一致；阳性 / 阴性对照和假阳性评估 | 仅凭“工具阳性”宣称已证明完整质粒 |
| 完整 / 环状结构 | 组装图、端点 / 跨接读段、候选序列 | 排除重复与错拼；多源结构支持 | 仅凭 ITR 或 header 证明闭环 |
| 功能与分型 | 序列、注释与数据库版本 | 匹配阈值、完整性、邻域、冲突解释 | 基因存在即耐药表型 / 活跃转移 |
| 宿主候选 | profile / MAG / 序列或物理证据 | 输入身份可追溯、多方法解释与竞争候选 | 共丰度即细胞内携带或因果 |
| 质粒多样性 | 统一 feature 矩阵、深度与归一化 | 样本 QC、非空矩阵、过滤与敏感性分析 | 原 contig 数即质粒丰富度；全零距离 0 即相同生态 |
| 差异丰度 | 独立重复、明确 contrast、适配的计数 / 组成数据与设计 | 模型诊断、效应量、FDR、混杂与配对控制 | coverage 取整即原始计数；≥3 重复即有功效 |
| 共变网络 | 统一矩阵、独立样本、混杂信息 | 稀疏性检查、重采样稳定性、统计误差与验证 | ≥20 样本即可信网络；相关即互作或水平转移 |

多样性 ≥3、内部差异每组 ≥3、网络 ≥20 为当前门槛。DESeq2 每组 ≥3 在脚本内写死，
不受 `min_group_replicates` 控制。门槛满足不是统计验收，缺少可识别设计的比较不作检验。

### F. 报告与科学验收

输出候选序列、结构依据、分型与功能表、宿主候选和证据类型、统一矩阵与统计记录、
工具 / 数据库版本、参数、输入校验和和完成 / 跳过 / 失败状态。
报告应由显式本次产物驱动，避免 publish 异步和旧 outdir 污染。

当前工程测试与生物学验证分别记录；合成 mock 不用于估计真实检出率或假阳性率。

## 5. 实施优先级与未解决项

1. **优先处理可比性**：catalog 回贴、稳定 ID、未检出与缺失区分、多重比对策略。
2. **修正计量和设计**：真正计数、归一化分母、可识别 contrast、配对 / 批次及组成性。
3. **核验结构和宿主链**：ITR 标记语义、MAG 输出路由、q 阈值、长读替代解释。
4. **补齐真实验收**：固定数据库和环境，阳性 / 阴性对照，小规模真实数据端到端，报告完整性。

上述是实施要求，不是就绪或成功声明。任何高成本计算仍应先形成具体执行计划；本任务只整理框架与审查事实。
