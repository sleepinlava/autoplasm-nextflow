              INPUT CONTRACT / 样本身份先于分析
              
一张 TSV，描述平台所需的材料。

              

                sample_id · group · read1 · read2
long_reads · assembly ·
                pod5 · bam
host_reference · notes
              

              

                按平台提供对应文件。sample_id 全表唯一，符合
                [A-Za-z0-9][A-Za-z0-9_.-]*；显式元数据沿 tuple(meta, files)
                通道传递，避免用文件名猜测样本身份。

05 / Design notes & provenance

              
设计说明，也保留实现边界。

            

            

              主线展示通用平台；完整当前接线以平台路线文档为准。审查结论作为补充，帮助区分设计能力、实际接线与已验证结果。
            

          


          

            跨样本统计对象与定量边界
            

              当前 DIVERSITY、内部差异、DESeq2 / 网络读取共享 plasmid
              表。通用入口以全组装精确/反向互补去重参考进行全部样本竞争重映射，
              MMseqs2 比较目录保持独立。CoverM 请求 mean / TPM / RPKM / count，
              raw_count 是 read 比对数，双端 mates 分开；protocol 则使用合格 paired fragments。
              两种计数契约不能混用，coverage 取整也不能代替计数。
            

          


          

            结构、MAG 与宿主关联的限制
            

              ITR 单独出现时拓扑为未知；DTR/header 的 circular 仍是候选。
              MAG 默认关闭，单 binner 或显式 DAS Tool 产生最终 bins；protocol 使用
              PlasMAAG cellular bins。CRISPR 未实现。群落 profile、序列相似与共变
              关联均不能升级为物理宿主或直接转移证据。
            

          


          

            事实审查与验证记录
            

              完整的 22 项事实可靠性审查保留早期源码依据和方法资料。历史43
              项单元回归通过支持已有脚本行为；真实数据库端到端和生物学准确性需单独验收。早期
