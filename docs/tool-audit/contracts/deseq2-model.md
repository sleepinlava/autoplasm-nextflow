# DESeq2模型、分组元数据与统计输入保护

开始于2026-10-22，最终验收2026-10-23；TA-011/061/062/063/064/065/066。证据 `results/tool-audit/20261022-deseq-model/receipt.json`；最终receipt的源码/包锁/数据及命令约束本契约，不外推其他profile或工具效果。

固定目标为原声明的DESeq2 1.42.0：原生R4.3.3/185包显式URL+MD5锁，全部installed版本/build/SHA256/MD5核对，实际库版本检查。旧Conda允许>=1.40，故旧输入改写对照明确选本机1.52；这不是默认1.42镜像或跨版本数值一致性认证。没有升级生产统计模型，也没有执行镜像、远端executor或nf-test框架。

官方[1.42固定提交AllClasses.R](https://github.com/thelovelab/DESeq2/blob/17a39b5296cb3d897f1e2a9aa4bebbdefb13b46a/R/AllClasses.R#L355)要求非负整数矩阵，并在构造时明确拒绝全零。原生对照发现：未重排的xtabs可用；按生产路径重排后变为table，as.matrix仍保留table，固定栈S4转换丢dim/dimnames而报assays不平行。相同数值/顺序/dimnames的普通矩阵成功。现在先检查完整唯一sample×feature矩阵，再构造普通整数矩阵；不通过计数取整、覆盖度替代或升级库绕过错误。

保留原方法：全设计~group只拟合一次，再逐对contrast；>=10计数在至少最小实际分组大小的样本中出现的预过滤；默认ratio大小因子、独立过滤和BH；未引入lfcShrink或自动更换拟合/归一化方法。独立R脚本仍支持显式--sf-type poscounts，工作流默认ratio。宽矩阵官方API参考程序不复用生产长表导入/状态代码；核对两组、三组联合模型、实际对比键、数值、受控强信号方向/q值及标签变换。它不是真实生物学准确率或功效基准。DESeq2的log2_fold_change对应group_a/group_b；内部效应量log2fc为加原有1e-6伪计数后的group1/group2平均coverage比值，两者输入量与模型不同。

每组最小重复数现在由min_group_replicates传到两个差异节点，默认3；正整数校验拒绝小数截断、0/负数、非有限值。DESeq2 min1但无残差自由度时明确不可估计。网络默认20不变，null才使用默认，显式0不会再被Groovy真假值规则偷偷改回20；R端要求至少2的整数。这些是执行门槛，不是功效保证。

执行DESeq2节点时，结果文件仍为differential_plasmids.tsv，新增必需输出deseq2_status.tsv。状态包含全部输入sample_id、分组、进入设计/实际拟合标记、输入/过滤后文库大小、特征数、实际最小重复数/大小因子方法、拟合标记、已加载模型版本及contrast失败数。未加载模型时版本写not_loaded，不用配置冒充实际运行。

| 情况 | 行为 |
| --- | --- |
| 0特征、全零、无分组/分组不足、重复数不足或预过滤无特征 | 明确not_run原因，结果仅表头，保留完整cohort状态 |
| 无残差自由度、过滤后零文库、ratio没有正几何均值 | not_estimable；不删样本、不补计数、不伪造大小因子，不自动切poscounts |
| 输入缺测/重复/非整数/非有限/超R整数范围 | 带源文件/样本/特征诊断并失败，无正常结果发布 |
| 真实拟合成功 | completed、实际1.42版本、逐对结果；模型一般错误继续失败并阻止报告 |
| 单个contrast捕获错误 | 保留原NA/warnings策略，状态completed_with_contrast_failures及计数；不能当作完整成功 |

三个统计消费者用一致的标准TSV元数据解码，保留分组中的引号/制表符/换行；适当转义结果和状态。不以物理行数代替复杂TSV的逻辑记录数。旧DESeq/内部结果100条被读成200，旧alpha24条被读成36；独立CSV解析器核对当前100/100/24及原始标签。fread保留双写引号的本地行为有独立对照，不能只修输出而忽略导入。缺失NA分组的前后对照都不生成假组，不作为新缺陷计数。

四个统计wrapper分别暂存abundance/*与cohort/*。旧包装器在私有同名输入上成功执行后改写上游源表，当前同名输入/输出和两份输入同名均不改源。默认CROSS_SAMPLE规范产物名原本未碰撞，不能声称所有旧主流程都损坏。旧对照只允许私有fixture被改写；原数据hash与改写后hash均留存。

原CROSS_SAMPLE验证状态输出作为本次完成证据进入报告，未改变REPORTING只暂存检测计数材料的设计；核对证据路径指向本次DESEQ2工作目录及发布状态hash。缓存不变命中，阈值改变重新计算模型和报告；失败不发布报告。两个统计节点同时启用另验。

测试证据分层：固定版本模型/接口、独立数值/标签/文件源不变、真实固定DNA+明确模拟reads的共享重映射、外部工具observer的平台连接分别登记。TT-003加强状态/数值断言但仍缺nf-test/完整真实非空P4；TA-016完整CLI/DB/model身份与TA-039真实宿主阈值不由本契约认证。初稿错误（PATH配置引号、恢复会话选择、报告暂存假设、缺失诊断路径、TSV转义不足）、有意中断与部分清单保留；仅最终完整源码对应结果可接受。
