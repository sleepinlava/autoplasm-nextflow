# TETRA 来源宿主基准：数值通过，通用阈值未通过

2026-10-23基准记录：当时TA-039保持S0/ready，不能用本次失败结果关闭科学验收。2026-10-24用户另行决定保留分数、停用未校准链接，当前输出见 [TETRA仅分数契约](tetra-score-only.md)。当前生产方法为 `tetra_markov256_v1`；本次没有改写生产代码或阈值，也没有在留出集上重新选择阈值。

## 标签与适用范围

来源为已锁定完整 OPERA-MS 参考归档中的真实 DNA。评分前按固定 SHA 顺序选取20个旧 header 属各3份组装，共60候选；实际 NCBI nuccore/taxonomy 元数据确认精确 accession/version、长度、完整性、质粒/染色体类型、同一非空 BioSample 和 source TaxID 后，保留55份，5份排除，不补选。当前 taxonomy 对应26个属，不能用旧目录名替代实际分类。

终点严格为 `recorded_assembly_host`：同一来源 BioSample 为正确来源，其他来源的代表染色体是来源归属 decoy。它们**不是实验上不允许感染/转移的宿主**。每来源仅一条代表染色体，未代表全部染色体、MAG 质量分布或真实转移宿主范围。来源为完整10kb–500kb质粒，另各取3个固定 SHA 位置的500bp/1kb/5kb/10kb连续片段。

BioPython SeqIO 独立检查55对原始 DNA/元数据、715个查询记录、55条染色体及15,130个标签配对；片段必须逐字对应父质粒的已锁定坐标。500bp的165个查询仅作短序列哨兵，按生产1000bp最短比较长度排除，不能把缺分数作为阴性。

## 评分前冻结的分组和验收

全部55条完整质粒实际运行 BLASTn2.10.1（`blastn`、word_size11、dust=no、55 targets）。对 identity≥95%的 HSP 分别取 query/subject 覆盖并集，两者均≥80%时连接，得到54个质粒簇；唯一近缘边为 NC_003922.1 / NC_020797.1。该规则只作泄漏屏障，不定义生物物种。独立整数位集覆盖 oracle 与准备阶段的区间合并结果一致。

宿主组保守合并同一当前属 TaxID、旧 header 属或 BioSample；同时联合近缘质粒簇，得到20个不可跨集合的来源连通分量。按事先固定 SHA 排序分配至较小集合，形成27来源 calibration、28来源 holdout，各10个分量。BioSample、宿主组、质粒组均不跨集合；分组、数据、片段位置、标签和验收均先于 TETRA 分数冻结。

仅用完整质粒 calibration 集选择 `[0,1]` 内阈值：precision≥0.9时最大化 balanced accuracy，并列先 specificity 再较高阈值。选定阈值固定用于完整质粒及1kb/5kb/10kb片段的 holdout，禁止片段单独拟合或留出集反调。所有4层均须 precision≥0.9、sensitivity≥0.5、至少10个**不同父质粒**产生预测阳性、正确来源配对可评分率≥0.9，才允许提出共用自动阈值。

评分前另存说明：不把窗口或配对当作独立生物重复；以查询来源连通分量为单位，固定 seed、1000次 cluster bootstrap，报告给定宿主目录条件下的区间。宿主目录不重抽，阈值不重拟合；不提供总体宿主范围置信结论。无预测阳性的重抽样中 precision 未定义，数量明确记录，不能补零或省略该事实。

## 数值与实际阈值结果

原生产 R4.6.1 / Biostrings2.80.2 比较550个长度合格查询与55条染色体，共30,250对；29,700对完整可评分，550对 profile 不可评分。独立 C++ 双链滚动计数经7个逐窗口边界控制核对，再由 Python 标量 Markov 公式及 `fsum` Pearson 计算；全部分数与生产 R 一致，最大绝对差 `3.3306690738754696e-16`（容许差1e-10）。全部 ID、方法、未校准标签、短序列排除和0.7输出选择逐对核对通过。

校准工具真实 CLI 退出0，状态是 `estimated_on_supplied_labels`，**不代表科学验收通过**。独立重新计算全部候选阈值、混淆矩阵和选择顺序，结果一致：选定阈值 `0.9534655970247977`。训练集完整质粒仅 TP=1、FP=0、FN=26，精确率100%而召回率3.7%，只有一个父质粒被选中。
